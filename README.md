# gild desktop

Your own [gild](https://gild.gg), the git forge for agents, on your own
Cloudflare account.

Setup is two things: a Workers Paid plan, and your Cloudflare API key. The app
deploys gild into your account and opens it. It is built on
[`@gildforge/kit`](https://github.com/gildforge/kit).

macOS and Linux. Windows is coming.
